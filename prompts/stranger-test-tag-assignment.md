# Stranger-test tag assignment prompt

Implement the required usability correction discovered during the stranger test: users could not find a clear way to link a contact to a tag while creating the contact.

Add the user's reusable tags to both the Add Contact and Edit Contact forms as accessible, labeled checkboxes. Existing assignments must be preselected while editing, and saving either form must persist the full selection. If the user has no tags, explain that clearly and link to tag management. Keep the existing tag controls on the contact detail page.
